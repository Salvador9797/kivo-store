# Política de privacidad de Kivo

Actualizada: 28 de octubre de 2026. Aplicación: Kivo (`app.kivo.market`). Responsable del proyecto: Salvador9797, mantenedor del repositorio Kivo Store.

## Datos en el dispositivo

Kivo consulta las aplicaciones que Android permite detectar en el perfil actual, sus paquetes y versiones para mostrar Abrir y buscar actualizaciones compatibles. El inventario se procesa localmente; no se publica como lista. Las consultas de actualización pueden comunicar a la fuente correspondiente el identificador de la aplicación o del proyecto consultado.

El catálogo, preferencias, búsquedas recientes, borradores, archivos descargados y datos de sesión pueden guardarse en el dispositivo. Los tokens de acceso se cifran mediante Android Keystore. Kivo no pide la contraseña de GitHub ni de itch.io.

## Servicios externos

Kivo se conecta a F-Droid, IzzyOnDroid, GitHub y, cuando se usa su integración, itch.io para obtener catálogos, imágenes y descargas. Las conexiones comunican la dirección IP y los datos técnicos habituales de una solicitud; cada proveedor aplica su propia política. Los juegos web pueden cargar contenido de terceros dentro de su visor y están sujetos a las prácticas de sus autores.

Conectar una cuenta es opcional para las funciones que no requieren autenticación. GitHub se usa también para comentarios y calificaciones: el nombre público de la cuenta, el texto y la calificación publicados son visibles para otras personas. No publiques datos personales en comentarios. El acceso de GitHub puede solicitar el permiso public_repo; revísalo en la pantalla de autorización.

La traducción en línea es opcional y, después de la confirmación, envía la descripción pública de la app a MyMemory. La opción de traducción local depende de las funciones disponibles en Android.

## Métricas y publicidad

La versión 0.9.13 no incorpora un servicio propio de analítica de uso ni un SDK publicitario. Los proveedores externos pueden registrar las solicitudes que reciben.

## Control y eliminación

Puedes desconectar las cuentas desde Kivo y revocar sus autorizaciones desde el proveedor. Borrar los datos de Kivo o desinstalarla elimina sus datos privados locales; los archivos exportados o guardados fuera de ella pueden permanecer. Los comentarios públicos alojados en GitHub no se eliminan al desinstalar Kivo y deben gestionarse en GitHub. Los proveedores determinan la conservación de sus propios registros.

## Contacto y cambios

Para consultas de privacidad, contacta con el mantenedor mediante https://github.com/Salvador9797/kivo-store/issues. Ese canal es público: no envíes contraseñas, claves de firma ni información sensible. Esta política puede actualizarse cuando cambien las funciones o los servicios utilizados.
